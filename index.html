Final-year project: an artificially intelligent SIEM for targeted threat detection, using federated logistic regression to cut false positives.

  • Flower, scikit-learn, and the UNSW-NB15 dataset.
  • The model was moderate. Overfitting showed up as high loss, which is written up honestly.
